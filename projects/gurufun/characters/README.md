# GuruFun — референсы персонажей

Заказчик: GuruFun (guru.fun), community pad на Solana. Аудитория: Китай и Индия.
Задача на 19.10.2026: собрать 10–15 персонажей с китайским и индийским культурным кодом и лором. Каждый персонаж ведётся в отдельном чате.

Правила:
- Каждый персонаж в своей папке `NN_имя/`: канон `имя_main.jpg` и файл `имя.md` (лор, блок героя для Flow, что не сработало).
- Культурный код в герое, предметах и меме, а не в народной росписи («не хохлома»).
- Контраст в образе, характер на морде, форма узнаётся силуэтом.
- У каждого персонажа своя манера рисунка, без повторов (решение 19.10.2026). Занято: 01 — взрослый мультфильм с тушью, 02 — маньхуа, 04 — татуировочный флэш, 05 — рисованное граффити, 06 — гладкий плоский мультфильм из пиксель-арта (манеру 03 смотреть в его папке).
- Тикер 3–6 знаков (правило GuruFun). Без чужих брендов, реальных людей, религиозных символов, обещаний прибыли.
