# Ten Keys — промты для Flow

Канон выбран 06.10.2026: ключ от хранилища (круглая головка-кольцо, длинный стержень, бородка с квадратными зубцами).
Две картинки из кастинга сохранить как референсы:
- `references/tenkeys_main.jpg` — два ключа строго сверху, головками вверх;
- `references/tenkeys_main_angle.jpg` — два ключа крупно под углом.

## Настройки

- Количество `x4`, модель Nano Banana Pro: один промт даёт четыре отдельных варианта.
- Каждый промт начинается с «One single … image». Начало «Generate 4 separate images» не использовать: 06.10.2026 веб-версия на него нарисовала одну картинку-сетку из четырёх ключей.
- К каждому промту приложить оба референса через плюс в поле ввода.
- Формат: для логотипа и галереи `1:1`, перед двумя баннерами переключить на `16:9`.

Правило одно и для компьютера, и для приложения на iPhone.

## На что смотреть при выборе

- Форма ключа как на каноне.
- Оранжевый предмет ровно один.
- Ключей, долей и засовов столько, сколько сказано. Пересчитать.
- Нигде нет букв, цифр и логотипов.
- У баннеров левая треть пустая.

## После генерации

Выбранные картинки разложить по папкам `references`, `logo`, `gallery`, `banners` в `projects/tenkeys/brand`. Длинные имена из Flow можно не менять: ассистент откроет каждую картинку, сверит с именем и переименует.
Для логотипа нужен один файл `logo/tenkeys_logo.jpg`: лучший из трёх вариантов выбирается по превью в круге 48 пикселей.
