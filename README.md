# memecoin-kit

Reusable kit for building memecoin and utility-token projects fast.

## Structure

- `projects/<name>/` — one folder per project: `project.config.json`, `brand/`, `launch/`, `case/`, `README.md`
- `templates/landing/` — site template (Astro + Tailwind): one codebase, many sites
- `docs/how-to-stamp-a-site.md` — how to build a new site from the template, step by step
- `portfolio/pitch.md` — texts for resume, portfolio and outreach
