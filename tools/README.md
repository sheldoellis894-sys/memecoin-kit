# tools — рабочие скрипты

Эти скрипты запускает ассистент. В архивы для заказчиков папка `tools/` не попадает

| Скрипт | Что делает | Где запускать |
|---|---|---|
| `check_texts.py` | Проверяет тексты по правилам Дениса: точки в конце абзацев, длинное тире в ТЗ, запрещённые слова («кривая», «шортер», «anon»), английские слова в русском тексте, обороты ИИ, повтор заголовков, двойные пробелы | компьютер или облако: `python3 tools/check_texts.py <файл> --mode site\|tz\|team` |
| `check-devices.mjs` | Открывает сайт на 13 профилях (iPhone, Android, телефоны на боку, iPad, Android-планшет, ноутбуки, большие экраны), ищет прокрутку вбок, вылезающий текст, ошибки консоли, битые картинки, мелкие кнопки; собирает `report.html` и `contact-sheet.png` | облако (нужен playwright и браузер): `node tools/check-devices.mjs templates/landing/dist --out /tmp/check` |
| `pack_handover.py` | Собирает архивы для передачи заказчику по списку `projects/<имя>/handover.json`, не пропускает лишнее (.env, data/, node_modules, .git, абсолютные пути, личная почта, имена других проектов), показывает разницу с прошлой версией | компьютер (`--images` — в облаке, там есть Pillow): `python3 tools/pack_handover.py projects/<имя>/handover.json --dry` |
| `preflight.py` | Одна проверка перед сдачей: тексты, экспорт Figma, ссылки README, снимки кейса, `state.md`, учёт времени, секреты (ключи, пароли, токены) в проекте, коде и сборке, SEO сборки (title, description, canonical, og, robots.txt, sitemap) | компьютер: `python3 tools/preflight.py projects/<папка> --site <dist> --code <папка кода>` |
| `check_exports.py` | Проверяет экспорт из Figma в `brand/exports`: шесть файлов и их размеры, белые и прозрачные полосы по краям, прозрачные углы круглого аватара, вес для pump.fun, файлы с именами кадров Figma и файлы чужого проекта. `--rename` переименовывает кадры, `--favicon` делает фавикон 256 | облако (полная проверка) или компьютер (только размеры): `python3 tools/check_exports.py projects/<имя> --rename --favicon` |
| `cutout.py` | Вырезает героя и предметы с зелёного, розового или синего фона Flow, режет листы эмоций и поз на отдельные фигуры, ставит всех в один масштаб и на одну линию, делает лист проверки на тёмном и светлом фоне | облако: `python3 tools/cutout.py <картинки> --out <папка> --split --size 640 --same-scale --align bottom --check` |
| `contact_sheet.py` | Собирает пачку картинок на один лист с именами, размерами и весом: проверить генерации одним взглядом | облако: `python3 tools/contact_sheet.py <папка> --out sheet.jpg --newer-than 2026-11-16` |
| `new_project.py` | Заготовка нового проекта: папки, бриф, учёт времени, файл промтов, тексты сайта, файл состояния `state.md`, конфиг, для заказчика — `handover.json`. Ничего не перезаписывает | компьютер: `python3 tools/new_project.py <папка> <префикс> --type meme\|utility\|agent\|client` |
| `security/cloudflare-security-audit/` | Скилл Cloudflare для аудита безопасности с независимой перепроверкой находок (MIT, скачан 18.11.2026 с github.com/cloudflare/security-audit-skill). Ассистент читает `SKILL.md` и работает по нему; полный режим запускает несколько агентов | облако, по согласию Дениса |
| `handover.example.json` | Образец списка для `pack_handover.py` (по составу архивов Mr. MA) | — |

Настоящий Safari `check-devices.mjs` не заменяет: профили iPhone и iPad открываются в Chromium с размерами и касаниями iPhone. Последняя проверка iPhone — на телефоне владельца

Образцы текстов для команды лежат в `docs/templates/`: `pitch.md` (короткий питч идеи) и `tz.md` (ТЗ для разработчика)

На компьютере Дениса нет Pillow, numpy и scipy, поэтому всё, что работает с картинками, запускается в облаке: файлы забираются из папки, обрабатываются и кладутся обратно
