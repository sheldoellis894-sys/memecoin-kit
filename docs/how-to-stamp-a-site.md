# Как штамповать сайт

Один код — много сайтов. Сайт складывается из трёх файлов: конфиг проекта, тема и макет.
Код шаблона при этом не меняется. Меняется он только тогда, когда нужна новая секция или новая игра.

## Что есть в шаблоне

| Что | Варианты | Файл |
|---|---|---|
| Темы | `mine` (тёплая тёмная, скруглённые карточки), `sunset` (пиксельные шрифты, квадратные панели, жёсткие тени), `office` (листы бумаги на столе тёмного дерева) | `templates/landing/src/themes/<тема>.json` |
| Макеты | `longread`, `arcade` (экран загрузки и главный экран как заставка игры), `contract` (сайт-документ: листы, закладки папки, подпись) | `templates/landing/src/layouts/<макет>.json` |
| Секции | `header`, `hero`, `heroArcade`, `boot`, `marquee`, `about`, `digGame`, `chaseGame`, `howToBuy`, `tokenomics`, `gallery`, `roadmap`, `footer` | `templates/landing/src/sections/` |
| Секции макета `contract` | `paperFx`, `paperTabs`, `bossGrow`, `paperCover`, `paperClauses`, `feedGame`, `paperDuties`, `paperPayroll`, `deskPhotos`, `paperOrders`, `paperSign`, `paperFooter` | `templates/landing/src/sections/paper/` |
| Игры | `digGame` — выбери клетку; `chaseGame` — бег с прыжками; `feedGame` — лови падающую еду | настройки в конфиге: `game`, `chase` и `feed` |

## Новый сайт за шесть шагов

1. **Папка проекта.** Создать `projects/<имя>/brand/` с подпапками `docs`, `references`, `logo`, `banners`, `exports`, `gallery`, `stickers`, `video`.
2. **Картинки.** Разложить по подпапкам. Имена: маленькие латинские буквы, цифры и `_`, одно расширение.
3. **Конфиг.** Скопировать `project.config.json` из похожего проекта и заменить тексты, ссылки и пути к картинкам.
   Для сайта с игрой «выбери клетку» брать за основу `projects/molty`, с бегом — `projects/tsc3000`, для сайта-документа с игрой «лови еду» — `projects/fch`.
4. **Тема и макет.** В конфиге указать `"theme"` и `"layout"`. Нужен новый стиль — скопировать файл темы, поменять цвета и шрифты.
5. **Проверка.** В `templates/landing`:
   `$env:PROJECT="<имя>"; npm run dev -- --host 127.0.0.1` → открыть `http://127.0.0.1:4321`.
6. **Публикация.** `git add -A`, `git commit`, `git push`. На Vercel: новый проект из того же репозитория,
   Root Directory `templates/landing`, переменная `PROJECT=<имя>`. Имя проекта на Vercel задаёт адрес сайта.

## Что настраивается в теме

```json
{
  "name": "sunset",
  "flavor": "arcade",
  "colors": { "bg": "", "surface": "", "text": "", "muted": "", "primary": "", "onPrimary": "", "secondary": "", "accent": "" },
  "fonts": {
    "heading": "Press Start 2P",
    "body": "VT323",
    "googleFonts": "family=Press+Start+2P&family=VT323",
    "headingScale": 0.55,
    "headingMin": ".75rem",
    "headingLeading": 1.45,
    "bodyScale": 1.375,
    "ticker": "heading"
  },
  "radius": { "button": "0px", "card": "0px" }
}
```

- `flavor` — готовый характер оформления. Сейчас их два: `arcade` (игра 16 бит) и `paper` (бумага на столе, работает вместе с макетом `contract`). Без этого поля тема выглядит как `mine`.
- `fonts.hand` — рукописный шрифт для приписок красной ручкой (только `paper`).
- `headingScale` — уменьшает заголовки, если шрифт очень широкий. `bodyScale` — увеличивает основной текст, если шрифт мелкий.
- `ticker` — каким шрифтом набран `$ТИКЕР`: `heading` или `body`. Правило: тикер целиком одним шрифтом, иначе знак `$` выбивается.

## Что настраивается в конфиге помимо текстов

| Поле | Зачем |
|---|---|
| `shortName` | Короткое имя для шапки, если полное длинное |
| `ui` | Подписи над разделами и значок-разделитель: `icon` (символ) или `iconImage` (картинка) |
| `boot` | Строки экрана загрузки и текст кнопки (секция `boot`) |
| `chase` | Игра-бег: спрайты, подписи, текст для поста в X |
| `feed` | Игра «лови еду»: три позы героя, еда с очками, плохие предметы, длина раунда, подписи, текст для поста в X |
| `boss` | Герой у края страницы, который растёт при прокрутке: спрайт, подпись, вес от и до |
| `paper` | Все подписи макета `contract`: названия разделов, приписки ручкой, мелкий шрифт, тексты подписи, слово на печати, включение приёмов (`paper.fx`) |
| `assets.heroVideo` | Короткое видео без звука вместо фото на первом листе (макет `contract`) |
| `game` | Игра «выбери клетку»: поле, шансы, стикеры, реплики |
| `images` | `"optimize": true` сжимает картинки при сборке. `maxSize` — предел в пикселях для каждой подпапки |
| `effects` | Появление при прокрутке, параллакс, курсор (`cursorIcon`), искры по клику |

## Макет `contract`: сайт как документ

Сайт выглядит как стопка листов на столе. Обычные поля конфига остаются теми же, меняется только подача:

| Поле конфига | Чем становится |
|---|---|
| `tagline`, `hero.text`, `assets.hero` | Первый лист: бланк, заголовок, фото или видео на скрепке |
| `about` | Пункты договора с номерами, сбоку фото на скрепке |
| `howToBuy` | Список обязанностей с пустыми клетками |
| `tokenomics` | Ведомость: название, точки, значение |
| `gallery` | Фотографии на столе. Их можно таскать, по нажатию фото переворачивается. Поле `note` — записка на обороте |
| `roadmap` | Приказы: по одной карточке на этап, на каждой печать |
| `disclaimer` | Мелкий текст внизу, прямо на столе |

Разметка внутри текстов (`about.text`, `hero.text`, `howToBuy`, `tokenomics.items`, `paper.signText`):

- `[[текст]]` — замазанный текст, открывается при наведении или нажатии;
- `~~текст~~` — зачёркнуто красной ручкой;
- `{{текст}}` — приписка красной ручкой.

Приёмы оформления (`paper.fx`, каждый можно выключить): `stamps` — печать по клику, `pen` — приписки появляются при прокрутке, `redact` — замазанный текст, `loupe` — лупа над мелким шрифтом. Растущий герой включается секцией `bossGrow` и полем `boss`, подпись с кнопкой покупки — секцией `paperSign`.

Номера страниц «Page 2 of 7» считаются сами по порядку секций в макете.

## Картинки для игры «лови еду»

Нужны спрайты с прозрачным фоном: герой в трёх позах (ловит с открытой пастью, жуёт, недоволен), четыре вида еды, два плохих предмета.

- Герой: вид строго спереди, стоит в полный рост, все три позы одного размера.
- Предметы можно заказать одной картинкой сеткой 3×2, затем разрезать.
- Фон выбирать по герою. Если в герое или предметах есть зелёный, фон делать ярко-розовым (`#FF00FF`), иначе при вырезании пропадут зелёные части.
- Розовый фон даёт розовый отсвет на белом меху, его надо убирать при вырезании.

## Картинки для игры-бега

Нужны спрайты с прозрачным фоном: два кадра бега, прыжок, падение, соперник, предмет для сбора, препятствия.

- Генерировать каждый спрайт отдельной картинкой на ровном ярко-зелёном фоне (`#00FF00`), вид строго сбоку, герой смотрит вправо.
- Исходники называть с `_raw` на конце: `tsc3000_run1_raw.jpg`. Такие файлы на сайт не попадают.
- Готовые спрайты — без `_raw`. Кадры бега должны быть одной высоты, остальные спрайты героя в том же масштабе.

## Правила, набитые на первых проектах

- **Анимация 16:9 делается только из исходника 16:9**, вертикальная — из 9:16. Из квадрата выходит квадратное видео.
- **Для анимации герой должен быть крупным**, в середине кадра. Из сцены, где герой мелкий, генератор сам приближает камеру и перерисовывает героя по-своему. Движение просить простое, камеру неподвижную. Конец ролика проверять по кадрам и обрезать, если герой «поплыл».
- **Видео для сайта — отдельный лёгкий файл** без звука (960×540, до 1 МБ). Полный ролик 1080p остаётся для pump.fun и X.
- **Баннер во Flow — 16:9**, формата 3:1 там нет. Героев держать небольшими и в нижней части кадра, тогда обрезка до 1500×500 в Figma проходит без потерь.
- **Текст на картинках — белый с тёмной обводкой.** Цветной текст на пёстром фоне не читается.
- **В галерее только квадратные сцены и логотип.** Широкая картинка ломает ритм ленты.
- **Всё, что лежит в `brand/`, кроме `docs/` и файлов `_raw`, публикуется на сайте.** Черновики, архивы и картинки, которые не должны быть публичными, класть в `docs/`.
- **Чужие бренды и персонажи на картинках.** Генератор может сам дорисовать плакаты, логотипы или технику известных марок. Такие картинки перед публикацией проверять и переделывать.
- **Имена файлов на GitHub чувствительны к регистру**, в Windows — нет. Расширения сверять.
- **Запятые в JSON.** Лишняя или пропущенная запятая ломает сборку: смотреть вкладку PROBLEMS в VS Code.
- **Проверять на двух ширинах:** компьютер и телефон. Длинные слова и числа в пиксельном шрифте занимают много места.
- **На сайте и в постах нет обещаний прибыли**, внизу страницы обязателен дисклеймер.

## Когда всё-таки нужен код

- **Новая секция:** создать файл в `src/sections/`, зарегистрировать в `src/pages/index.astro`, добавить имя в макет.
- **Новая игра:** отдельная секция по образцу `ChaseGame.astro` или `paper/FeedGame.astro`. Тексты и картинки брать из конфига, цвета из темы.
- **Новый характер оформления:** блок правил `.flavor-<имя>` в `src/styles/global.css`.
- **Новый макет с собственными секциями:** секции класть в отдельную подпапку `src/sections/<макет>/`, эффекты подключать отдельной секцией (как `paperFx`), а не через общий `Effects.astro`. Тогда страницы старых проектов не меняются ни на байт.

После любой правки шаблона пересобрать все существующие проекты и убедиться, что они выглядят как раньше.
