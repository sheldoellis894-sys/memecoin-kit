## 8 дыр из видео и что их закрывает

1. Ключ от ИИ в коде страницы — `preflight` ищет ключи в коде и в сборке; ключи только в переменных Vercel
2. Пароли открытым текстом, чужие данные по номеру, инъекции — OWASP Security Audit
3. Админка без пароля или без защиты от подбора — OWASP; правило: пароль от 16 символов, сервер не запускается со слабым
4. Нет лимита на токены ИИ — Serverless Audit (лимиты в памяти не работают на Vercel) + лимит трат у поставщика модели (ставит Денис)
5. Нет мониторинга — ежедневная проверка сайтов
6. Нет тестов пользовательских путей — `check-devices.mjs` (вёрстка), тесты агентов, code-review-harness (запускает код). Сквозных тестов «зашёл — проголосовал — нажал купить» пока нет
7. Форма собирает данные без политики — не закрывается скиллом. Правило: не собирать телефоны и почты без нужды; для проектов заказчика — страница о данных (IP для страны, счётчики без cookies). Вопросы права — к юристу
8. Хранение данных граждан РФ и РК за рубежом — к нам почти не относится: личных данных не собираем
