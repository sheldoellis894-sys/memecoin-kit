Правило: в текстах стоит только подтверждённый срок. Цель переходит в текст после проекта, сделанного за это время.

## Что менять после каждого проекта

1. Добавить строку в таблицу «Проекты».
2. Обновить колонку «Подтверждено» в таблице «Сроки».
3. Во всех текстах ниже заменить срок «2 рабочих дня» на новый подтверждённый.
4. В блоке «Пример» добавить ссылку на новый проект (держать 2–3 лучших, не все).
5. С третьего проекта добавить в сообщение команде строку «В портфолио N проектов: мемкойны, утилиты, ИИ-агенты».
6. После первого проекта с ИИ-агентом добавить в список «Что получает команда» пункт про агента.
7. После реального запуска добавить цифры: держатели, объём, участники в Telegram.
